# Third-party notices

ContextDock implements its own tenant boundaries, memory records, retrieval, retention and dashboard. [Mem0](https://github.com/mem0ai/mem0) was a conceptual reference for contextual memory; this application does not depend on Mem0.

The application uses [sqlite-vec](https://github.com/asg017/sqlite-vec), [FastAPI](https://github.com/fastapi/fastapi), [Pydantic](https://github.com/pydantic/pydantic), HTTPX2 and Uvicorn. Their installed distributions retain their own copyright and license materials. Preserve those materials when redistributing dependencies. The application's own source is covered by [MIT](LICENSE).
